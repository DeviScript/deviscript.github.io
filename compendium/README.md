# Expert Technical Compendium

A self-contained reference for Full Stack Development, AI/ML, and Data Engineering — written for engineers who want to know more than most interviewers.

## Structure

```

├─ README.md                          ← This file
├─ FullStack/
│  ├─ Frontend.md                     ← React, hooks, state management, performance
│  ├─ Backend.md                      ← Node.js, APIs, event-driven systems
│  ├─ Databases.md                    ← SQL, NoSQL, indexing, query optimization
│  └─ DevOps.md                       ← Testing, CI/CD, deployment, monitoring
├─ AI_ML/
│  ├─ LLMs.md                         ← Architecture, embeddings, prompt design

├─ Data_Engineering/

```

## How to Use

Each file is **self-contained** — read any topic independently. Every file follows the same five-section structure:

1. **Definition / Theory** — Clear, foundational explanation of the concept.
2. **Practical Examples / Code** — Realistic, runnable code in context.
3. **Advanced Insights** — Performance considerations, trade-offs, scaling advice.
4. **Common Pitfalls** — Mistakes to avoid, tricky edge cases.
5. **Interview Tips** — How to explain the topic, what interviewers care about.
