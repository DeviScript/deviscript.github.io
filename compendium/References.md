# References & Further Reading

A curated reading list organized by domain. These are the most impactful resources for going deeper on each topic.

---

## Full Stack

### Frontend

- [React Docs — beta.reactjs.org](https://beta.reactjs.org) — The new React docs are excellent, especially the hooks guides
- [Josh Comeau's CSS/React blog](https://joshwcomeau.com) — Deep dives on animation, CSS, and React patterns
- _"High Performance Browser Networking"_ — Ilya Grigorik — networking fundamentals for web engineers

### Backend & APIs

- [HTTP/2 Explained](https://daniel.haxx.se/http2/) — Essential for understanding modern API transport
- [Hono docs](https://hono.dev) — Lightweight edge-native API framework
- _"Designing Web APIs"_ — Brenda Jin, Saurabh Sahni, Amir Shevat

### Databases

- [Use The Index, Luke](https://use-the-index-luke.com) — Free, excellent guide to SQL indexing
- [The Internals of PostgreSQL](https://www.interdb.jp/pg/) — Deep internals: buffer manager, WAL, MVCC
- [Drizzle ORM docs](https://orm.drizzle.team)

### DevOps & Testing

- [Testing Trophy — Kent C. Dodds](https://kentcdodds.com/blog/the-testing-trophy-and-testing-classifications)
- [The Twelve-Factor App](https://12factor.net) — Still relevant for cloud-native apps
- [OpenTelemetry docs](https://opentelemetry.io/docs/)

---

## AI / ML

### LLMs

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — The original transformer paper
- [Andrej Karpathy — Let's build GPT](https://www.youtube.com/watch?v=kCc8FmEb1nY) — Best intro to how LLMs work from scratch
- [OpenAI Cookbook](https://cookbook.openai.com) — Practical patterns and code

### RAG

- [LangChain docs — RAG tutorial](https://python.langchain.com/docs/tutorials/rag/)
- [RAGAS paper](https://arxiv.org/abs/2309.15217) — Automated RAG evaluation framework
- [Advanced RAG Techniques](https://medium.com/towards-data-science/advanced-rag-techniques-an-illustrated-overview-04d193d8fec6)

### Model Evaluation

- [Hugging Face Evaluate library](https://huggingface.co/docs/evaluate/)
- [Evidently AI](https://www.evidentlyai.com) — Open-source ML monitoring and evaluation
- _"Reliable Machine Learning"_ — Cathy Chen et al. (O'Reilly)

### ML Pipelines & MLOps

- [MLflow docs](https://mlflow.org/docs/latest/index.html)
- [Weights & Biases](https://wandb.ai) — Experiment tracking
- _"Designing Machine Learning Systems"_ — Chip Huyen — Must-read for production ML

## Data Engineering

### ETL / ELT

- [dbt docs](https://docs.getdbt.com)
- [Apache Airflow docs](https://airflow.apache.org/docs/)
- [The Data Engineering Cookbook](https://github.com/andkret/Cookbook) — Free and comprehensive

### Data Modeling

- _"The Data Warehouse Toolkit"_ — Ralph Kimball — The definitive dimensional modeling book
- [dbt Best Practices guide](https://docs.getdbt.com/guides/best-practices)
- [Data Vault Alliance](https://datavaultalliance.com)

### Big Data & Streaming

- [Apache Kafka documentation](https://kafka.apache.org/documentation/)
- [Spark: The Definitive Guide](https://www.oreilly.com/library/view/spark-the-definitive/9781491912201/) — Bill Chambers & Matei Zaharia
- [Apache Iceberg docs](https://iceberg.apache.org/docs/latest/)

### Analytics

- [Mode Analytics SQL Tutorial](https://mode.com/sql-tutorial/) — Practical SQL for analysts
- [Causal Inference for The Brave and True](https://matheusfacure.github.io/python-causality-handbook/) — Free, excellent A/B testing & causal inference
- [Evan Miller — A/B Testing calculators and essays](https://www.evanmiller.org)

## General Engineering Fundamentals

- _"Designing Data-Intensive Applications"_ — Martin Kleppmann — The single best book on distributed systems
- _"The Pragmatic Programmer"_ — Hunt & Thomas — Timeless software engineering practices
- _"Clean Code"_ — Robert C. Martin — Code readability and maintainability
- [System Design Primer](https://github.com/donnemartin/system-design-primer) — GitHub repo, essential for system design interviews
- [Refactoring.Guru](https://refactoring.guru) — Design patterns explained visually
